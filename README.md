# DeCIpher

**DeCIpher** is an interactive, agent-first CLI tool designed to automate CI/Deployment troubleshooting.

## Core Mission
To provide a specialized "CI Engineer" agent that can:
- Triage failing pipelines and build logs.
- Automatically modify Dockerfiles, CI workflows, and deployment manifests.
- Iteratively **deploy -> test -> debug -> fix -> re-deploy** until the issue is resolved.
- Support all major AI API keys (OpenAI, Claude, etc.).

## Usage
Run the CLI tool:
```bash
decipher
```

## Hackathon Goal
Demonstrate a complete, automated loop of diagnosing and fixing real-world CI/Deployment failures within a structured demo scenario.
